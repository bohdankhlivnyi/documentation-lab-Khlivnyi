# Встановлення та запуск MediReminder

## 1. Загальна інформація

MediReminder — навчальний макет мобільного застосунку для нагадування про прийом ліків.

У цьому документі описано умовний процес встановлення, початкового налаштування та перевірки роботи застосунку.

## 2. Необхідні інструменти

Для використання MediReminder передбачено:

- Смартфон з Android або iOS.
- Доступ до інтернету для початкового встановлення.
- Дозвіл на надсилання сповіщень.
- Достатньо вільного місця для встановлення застосунку.

## 3. Встановлення

Оскільки MediReminder є навчальним макетом, наведені нижче кроки демонструють передбачений процес встановлення.

1. Відкрити магазин застосунків на смартфоні.
2. Знайти MediReminder.
3. Натиснути кнопку «Встановити».
4. Дочекатися завершення встановлення.
5. Відкрити застосунок.

## 4. Перший запуск

Після запуску користувач повинен:

1. Ознайомитися з головним екраном.
2. Надати дозвіл на сповіщення.
3. Відкрити розділ «Мої ліки».
4. Натиснути «Додати ліки».
5. Вказати назву ліків та час нагадування відповідно до призначення лікаря.
6. Зберегти створений запис.

Після цього нагадування має з'явитися у списку.

## 5. Перевірка роботи

Щоб переконатися, що застосунок працює правильно, необхідно перевірити такі дії:

| Дія | Очікуваний результат|
|---------------------------|---------------------------------|
| Запуск застосунку         | Відкривається головний екран    |
| Додавання ліків           | Новий запис з'являється у списку|
| Створення нагадування     | Час нагадування зберігається    |
| Настання часу нагадування | З'являється сповіщення          |
| Позначення прийому        | Відмітка додається до історії   |

## 6. Можливі проблеми

**Застосунок не відкривається**

Перевірте сумісність пристрою та спробуйте перезапустити застосунок.

**Не надходять сповіщення**

Перевірте дозволи на сповіщення в налаштуваннях смартфона.

**Нагадування не зберігається**

Перевірте, чи заповнені обов'язкові поля, та повторіть збереження.

## 7. Примітка

MediReminder не є готовим застосунком для встановлення. Цей документ демонструє запланований процес запуску та перевірки роботи навчального проєкту.
