# MediReminder

MediReminder — навчальний проєкт мобільного застосунку для нагадування про прийом ліків.

## Опис проєкту

Застосунок допомагає користувачам створювати нагадування про прийом ліків і стежити за власним розкладом.

Основна мета — зменшити ймовірність пропуску запланованого прийому та зробити розклад зручним для перегляду.

## Основні функції

- Додавання ліків до особистого списку.
- Створення нагадувань із зазначенням часу.
- Отримання сповіщень про запланований прийом.
- Позначення прийому як виконаного.
- Перегляд історії відміток.
- Редагування та видалення нагадувань.

## Для кого призначений

MediReminder може бути корисним людям, які регулярно приймають призначені ліки, а також тим, хто хоче зручно організувати свій розклад.

## Принцип роботи

1. Користувач відкриває застосунок.
2. Додає назву ліків.
3. Встановлює час нагадування відповідно до своїх призначень.
4. Отримує сповіщення у вибраний час.
5. За потреби позначає прийом у застосунку.
