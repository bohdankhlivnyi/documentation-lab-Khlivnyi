
# Огляд API MediReminder

## 1. Загальна інформація

API MediReminder призначений для обміну даними між мобільним застосунком і сервером.

Через API можна отримувати список ліків, додавати нові записи та створювати нагадування.

Це демонстраційний опис. Реальний сервер та API у навчальному проєкті не реалізовані.

## 2. Основні відомості

- Формат передачі даних: JSON.
- Методи запитів: GET, POST.
- Умовна адреса API: `/api`.
- Для успішних запитів використовуються коди 200 та 201.

## 3. Отримання списку ліків

**Endpoint:** `GET /api/medications`

Повертає список ліків, доданих користувачем.

### Приклад запиту

```http
GET /api/medications
```

### Приклад відповіді (200 OK)

```json
{
  "medications": [
    {
      "id": 1,
      "name": "Препарат А"
    },
    {
      "id": 2,
      "name": "Препарат Б"
    }
  ]
}
```

## 4. Додавання ліків

**Endpoint:** `POST /api/medications`

Створює новий запис про ліки.

### Приклад запиту

```http
POST /api/medications
Content-Type: application/json
```

```json
{
  "name": "Препарат В"
}
```

### Приклад відповіді (201 Created)

```json
{
  "id": 3,
  "name": "Препарат В",
  "message": "Запис успішно створено"
}
```

## 5. Створення нагадування

**Endpoint:** `POST /api/reminders`

Створює нагадування для раніше доданого запису про ліки.

### Приклад запиту

```http
POST /api/reminders
Content-Type: application/json
```

```json
{
  "medicationId": 3,
  "time": "09:00",
  "repeat": "daily"
}
```

### Приклад відповіді (201 Created)

```json
{
  "id": 10,
  "medicationId": 3,
  "time": "09:00",
  "repeat": "daily",
  "message": "Нагадування створено"
}
```

## 6. Коди відповідей та помилок

| Код | Назва | Значення |
|---|---|---|
| 200 | OK | Запит виконано успішно |
| 201 | Created | Новий запис створено |
| 400 | Bad Request | Некоректні дані запиту |
| 404 | Not Found | Запис не знайдено |
| 500 | Internal Server Error | Помилка сервера |

### Приклад помилки (404)

```json
{
  "error": "Not Found",
  "message": "Запис не знайдено"
}
```

## 7. Примітка

Наведені endpoint'и, JSON-запити та відповіді створені виключно для демонстрації технічної документації.

MediReminder є навчальним макетом. API не використовується для призначення ліків або визначення дозування.
